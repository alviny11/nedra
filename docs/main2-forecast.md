# MAIN-2: реальный CatBoost на 24 ноября 2024

Новый маршрут `POST /api/thickness/main-2/predict` рассчитывает все 580 сегментов трёх объектов MAIN-2 (5 786,5 м). Возвращает JSON с `pipelineId`, `modelId`, `forecastDate`, `count`, `source: live`, `csv`, `coverageByAsset`. CSV содержит ровно `id,segment_id,thickness_pred`. Обработчик вызывает CatBoost на каждом запросе; модель и построенные признаки кешируются до изменения файлов, готовый CSV не подставляется.

Используется cb_combined_d6_MAE, обученный на 1 079 примерах 2018/2022/2023, с историей толщины/соседей, геометрией и эксплуатацией. Дата — конец 2024-11-24; в признаках исключительная граница 2024-11-25. Исходники в models/main2-2024/data. Модель и порядок признаков в model.cbm и metadata.json. Метки 2024 не используются; готовых прогнозов и эталонных ответов в пакете runtime нет. Файлы с историческими толщинами нужны для построения признаков, включая ВТД 2023.

Main 2 автоматически рассчитывается при открытии; кнопка «Рассчитать прогноз» запускает повторно. Ошибка отображается явно, скачивание недоступно до успешного расчёта. Экспорт содержит только 580 строк Main 2. В остальных группах действует прежний маршрут и поведение; Main 4 не переключён на новую модель. Синтетические режимы/коррозионные часы не изменены и не управляют этим прогнозом.

## Запуск

```bash
python3.12 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements-main2.lock
npm run dev
```

Vite вызывает тот же Python-сервис отдельным процессом. Интерпретатор: `PIPETWIN_PYTHON`, затем backend/.venv/bin/python, затем python3. Можно задать путь к готовому совместимому окружению: `PIPETWIN_PYTHON=/path/to/python npm run dev`. На каждый запрос процесс реально запускает модель. Для постоянного бэкенда: `cd backend && .venv/bin/python -m uvicorn app.main:app --port 8000`; установить `VITE_API_BASE=http://127.0.0.1:8000` при отдельном фронтенде. В FastAPI модель загружается один раз на процесс, пока файлы не изменились. Прогноз не доступен в офлайн single-HTML без бэкенда; ошибка не заменяется сохранённым CSV.

## Проверка

`npm run typecheck`, `npx vitest run apps/web/src/features/pipelines/main2-forecast.test.ts apps/web/src/features/pipelines/catboost.test.ts`, из backend: `.venv/bin/python -m pytest tests/test_main2_thickness.py`.

Качество 2024 неизвестно: фактических ВТД нет. В ретроспективной проверке 2023 общий r выбранной модели — 0,717371; внутри объектов связь существенно слабее. Полное покрытие не означает подтверждённую точность на необследованных сегментах. Main 2 соединяет три паспортных объекта, длина каждого последнего сегмента ограничена паспортом.
