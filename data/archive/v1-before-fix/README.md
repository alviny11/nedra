# Результаты до исправления (v1)

Отчёты и модель, полученные кодом **до** исправлений, найденных при разборе ошибок на test-v1 / ood-v1 / heldout-v1
(см. `docs/validation.md`, раздел «Разбор ошибок v1 и исправления»). Хранятся для прозрачности: после разбора
этих наборов они больше не являются «нетронутыми», поэтому итоговые метрики считаются на новых наборах v2 с
другими диапазонами seed.

Прогоны v1 текущим кодом не воспроизводятся (изменилась логика D1/D2 и генератор комбинированных утечек);
сохранены только манифесты наборов, отчёты оценщика и артефакт модели logreg-v1.
