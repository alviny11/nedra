# Передача CatBoost в бэкенд

Модель: `cb_history_d6_MAE`, нативный файл `model.cbm`. Это уже обученная модель, переобучение не требуется. Среди сопоставленных сохранённых HGB/CatBoost/MLP её общий Pearson r на 147 сегментах 2023 равен 0,718676, r² — 0,516496. Это ретроспективная оценка, не гарантия качества на новых объектах. Превосходство над MLP по r очень небольшое. Модель НЕ использует эксплуатационные параметры.

## Файлы и запуск

- `predictor.py`: независимый от проекта адаптер, загрузка `.cbm`, фиксированный порядок признаков, преобразование результата в мм; также пересборка признаков из паспорта и очищенной истории.
- `metadata.json`: спецификация, порядок входов, временные ограничения и версии библиотек.
- `requirements.txt`: версии окружения, где проверен пакет; Python 3.12. Установить в отдельное окружение.
- `verify.py`: запустить `python verify.py` после установки зависимостей. Сверяет все 147 прогнозов с точностью 1e-12 и пересборку признаков из истории.
- `fixtures/`: настоящие данные для проверки, включая очищенную историю и паспорта. Не являются публичными примерами, не публиковать в открытом репозитории.
- `request_example.json`: один готовый запрос с признаками.
- `reference_training_pipeline.py`: исходный код подготовки и обучения для трассировки. Для работы адаптера не нужен; НЕ запускать его для переобучения при интеграции.

Использование в Python:

```python
from predictor import ThicknessPredictor, build_features
predictor = ThicknessPredictor('/path/to/model_package')  # один раз при старте
features = build_features(asset, segment_ids, prediction_date, cleaned_history)
prediction_mm = predictor.predict(features)
```

Также `predictor.predict(request['records'])` принимает уже рассчитанные признаки. Поля обязательны по схеме, но отсутствующие измерения передаются как JSON null, а не ноль. `nominal_mm` обязателен, конечен и больше нуля. Ошибку источника истории нельзя молча трактовать как отсутствие истории. На границе HTTP проверять типы, даты, допустимые ID, конечность координат/паспортных значений; исключения валидации возвращать как ошибку клиента, а не как успешный прогноз.

Выход адаптера — список остаточных толщин в миллиметрах в порядке входных записей. Нативный CatBoost выдаёт ОТНОШЕНИЕ к номиналу: `max(0, raw * nominal_mm)`. Не возвращать raw как миллиметры и не ограничивать верхнюю границу номиналом: это изменит проверенный прогноз. В ответе API сохранять `model_id`, ID объекта, сегмент, дату прогноза и единицу `mm`. Точный маршрут и формат ответа согласовать с существующим API бэкенда.

## Контракт построения признаков

Паспорт: `id`, `length_m` в метрах, `nominal_mm` в мм, `commissioned` — дата ввода. Сегмент `segment_id` — целое от 0, ширина 10 м; последнее неполное окно допустимо. Положение: `min((segment_id + 0.5)*10, length_m)/length_m`. Возраст в годах — число дней от ввода до даты прогноза / 365.25. Календарные даты без часовых зон.

Очищенная история: одна строка на `(id, segment_id, date)` с `target_mm` — минимальной остаточной толщиной зарегистрированной потери металла. На вход истории не подавать сырые строки дефектов без очистки и агрегации. Полные исходные критерии в `reference_training_pipeline.py:prepare`: валидная положительная остаточная/исходная толщина, допустимые координаты, явная потеря металла, после ввода, исключение строк за пределами объекта. При координате ровно на конце объекта сегмент ограничивается последним существующим окном.

Для точного воспроизведения модель использует историю с 2018-01-01 включительно до 2023-01-01 исключительно и строго до даты прогноза. Последняя доступная запись выбирается отдельно для каждого сегмента. Не подмешивать замеры 2023 в прогноз 2023. Адаптер сохраняет исходный фиксированный cutoff и не начинает автоматически использовать новые обследования для последующих лет: изменение этой политики — отдельная версия с повторной проверкой качества.

`previous_ratio` — предыдущая толщина / паспортный номинал. `has_previous` — 0 или 1. `years_since_previous` — дни после последнего замера / 365.25. При отсутствии истории отношение и давность — null/NaN, наличие — 0.

Для каждого радиуса 50/200/500 м берутся последние известные толщины других сегментов того же объекта при `abs(neighbor_segment_id - segment_id)*10 <= radius`. Сам сегмент исключается. Среднее и минимум вычисляются от отношений толщины к номиналу, count — число соседних сегментов. Нет соседей: mean/min = null, count = 0. История соседей может быть доступна даже без прошлого замера самого сегмента. Не ограничивать радиус краями произвольного батча запроса: история должна охватывать весь нужный объект.

## Ограничения интеграции

Номинальная толщина используется при построении исторических отношений и переводе результата в мм, хотя отсутствует среди 14 фактических признаков деревьев (в обучении была постоянной). Эксплуатация, включая параметры за 2023, в данной версии не влияет на результат. Если продукт требует реакцию на эксплуатацию, нельзя объявлять эту модель выполняющей такое требование.

Модель обучена на 932 примерах трёх объектов, оценена на 147 сегментах девяти объектов. Оценка касается зарегистрированных потерь металла. Для всех сегментов, новых объектов и новых лет это перенос, качество которого отдельно не подтверждено. Внутри объектов корреляция слабая; общий Pearson включает различие групп. Сопоставимость межгодовой истории имеет известные ограничения из аудита. API не должен выдавать прогноз за измерение или готовое решение о безопасности трубы.
